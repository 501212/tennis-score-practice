# tennis-score-practice
Tennis score counter implemented in C.
## Features 
-Enter `1` to add one point for Player 1
-Enter `2` to add one point for Player 2
-Invalid input will prompt and wait for re-entry
-Show real-time score of two players

## File list
-`tennis_score.c`:source code

## Compile & Run (MinGW Windows)
```bash
gcc tennis_score.c -o tennis_score.exe
tennis_score.exe
